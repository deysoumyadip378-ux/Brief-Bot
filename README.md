# 📑 Brief Bot — High-Speed Text & Document Summarizer

An intelligent text condensation tool powered by Groq's fast `llama-3.1-8b-instant` language model.

## Features
- **4 Summary Styles**:
  - *Executive Summary*: High-level takeaway synopsis.
  - *Bullet Points*: Concise enumerated list of core facts.
  - *One Paragraph*: Cohesive, condensed single paragraph.
  - *Key Takeaways*: Critical conclusions and highlights.
- **Length Control**: Short (1-2 sentences), Medium (1 paragraph), or Detailed (multiple paragraphs).
- **Live Metrics**: Real-time word and character counters.
- **Markdown Rendering**: Formatted output with Highlight.js code styling.
- **Export Options**: One-click clipboard copy and `.txt` file download.

## Getting Started
1. Open `index.html` in your web browser.
2. Click **Settings (⚙️)** to configure your Groq API Key.
3. Paste or type your text in the source panel.
4. Select your desired summary style and length, then click **Summarize**!
